# colinmarsch.ca

A minimal Jekyll site published with GitHub Pages.

## Add a blog post

From the repository root, run:

```sh
script/new-post "My post title"
```

This creates a dated Markdown file in `_posts`. Update its tags, replace the placeholder text, and commit it. The opening paragraph automatically becomes the homepage summary, so no separate excerpt is required.

You can also copy `_templates/post.md` manually and name it using the format `YYYY-MM-DD-post-title.md`.
